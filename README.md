# Predictive Churn & Customer Lifetime Value (CLV) Engine

## Project Overview
This repository implements an end-to-end Machine Learning pipeline for dynamic customer churn prediction and CLV calculation. Built to demonstrate predictive modeling, risk assessment, and time-series feature engineering for subscription models and SaaS telemetry.

## Key Features
- **Data Engineering & Preprocessing:** Data cleaning, cohort building, and time-series feature extraction.
- **Predictive Churn Modeling:** Classification pipelines using XGBoost / Scikit-Learn for high-risk customer segmentation.
- **Customer Lifetime Value Estimation:** Predictive modeling to calculate lifetime account value and churn risk scores.

## Tech Stack
- **Languages & Libraries:** Python 3.10+, Pandas, NumPy, Scikit-Learn, XGBoost
- **Analytics Concepts:** Predictive Data Science, Survival Analysis, Machine Learning Pipelines
